## 1. Какие данные обрабатываются

Сервис «СнабПро» может обрабатывать:
- адрес электронной почты, имя и данные учётной записи пользователя;
- название, адрес и реквизиты предприятия, если пользователь их вводит;
- контактные данные поставщиков, включая рабочие адреса электронной почты и телефоны;
- сведения о материалах, закупках, заявках, коммерческих предложениях, ценах, доставке и сроках;
- письма, полученные от поставщиков в подключённом Gmail-ящике, и вложения, которые пользователь просматривает или передаёт на обработку;
- технические журналы, сведения об ошибках и данные, необходимые для защиты учётной записи;
- технические данные браузера и локальное хранилище для работы интерфейса.

Пользователь должен иметь законное основание для передачи в сервис контактных данных поставщиков и содержимого деловой переписки.

## 2. Цели обработки

Данные используются только для:
- регистрации и аутентификации пользователей;
- предоставления доступа к рабочему пространству предприятия;
- ведения справочников материалов и поставщиков;
- создания и хранения закупочных заявок и черновиков писем;
- отправки запросов коммерческих предложений от имени подключённого пользователя;
- получения и сопоставления ответов поставщиков;
- извлечения текстовых данных из документов и подготовки их к проверке пользователем;
- сравнения цен, доставки, количества, НДС и сроков;
- обеспечения безопасности, устранения ошибок и поддержки сервиса.

Сервис не продаёт персональные данные и не использует содержимое почты для рекламы.

## 3. Gmail API и деловая переписка

При подключении Gmail пользователь явно предоставляет сервису разрешения, необходимые для отправки запросов поставщикам и чтения входящих ответов.

- Gmail используется для работы с закупками, а не для рекламных рассылок.
- Фоновая проверка входящих писем выполняется примерно раз в 10 минут.
- Письма сопоставляются с поставщиками и заявками по адресу отправителя и служебному идентификатору в теме письма.
- Текст письма и сведения о вложениях могут сохраняться в рабочем пространстве предприятия.
- Токен обновления Gmail хранится в зашифрованном виде на сервере.
- Пользователь может отключить интеграцию и отозвать доступ в настройках Google.
- На текущем этапе внешние AI API не используются для чтения почты или обработки документов. Если такие функции будут добавлены, цели, провайдеры и условия обработки будут раскрыты отдельно до включения функции.

## 4. Поставщики и инфраструктура

Для работы сервиса используются поставщики инфраструктуры и обработки данных, включая:
- Supabase — база данных, аутентификация, файловое хранилище и серверные функции;
- Google — Gmail API и OAuth-аутентификация;
- GitHub Pages — публикация интерфейса приложения.

Перед публикацией необходимо указать фактические регионы хранения данных, применимые договоры обработки данных и механизмы трансграничной передачи, если они требуются применимым законодательством.

## 5. Хранение и защита

Данные предприятий разделяются по рабочим пространствам. Доступ к данным ограничивается членством пользователя и его ролью. Серверные операции с почтой выполняются через защищённые функции; токены Gmail шифруются. Передача данных осуществляется по HTTPS.

## 6. Права пользователя

В зависимости от применимого законодательства пользователь может иметь право запросить доступ к своим данным, исправление, удаление, ограничение обработки, переносимость данных или отозвать согласие. Запросы направляются на **[контактный email оператора]**.

Отзыв Gmail-доступа выполняется также через настройки безопасности Google. Отзыв доступа не обязательно удаляет ранее сохранённые в рабочем пространстве письма и документы — порядок их удаления должен быть описан отдельно.
