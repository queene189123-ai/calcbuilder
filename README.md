# СнабПро — демоверсия системы снабжения

Кликабельный русскоязычный прототип кабинета закупок для производственного предприятия.

## Запуск
Откройте `public/index.html` в современном браузере. Render раздаёт каталог `public`.

## Что можно проверить
- Обзор закупок и событий снабжения.
- Справочник материалов: выбор нескольких позиций, поиск, фильтрация, добавление.
- Создание демонстрационной закупки с распределением по категориям поставщиков.
- База поставщиков: добавление и поиск.
- Поиск новых поставщиков (примеры явно помечены как вымышленные).
- Оптимизация расходов и рекомендации.
- История закупочных цен.
- Сохранение материалов, поставщиков и закупок в localStorage.

## Ограничения
Это фронтенд-прототип. Данные хранятся только в браузере. Нет регистрации, серверной базы, реальной отправки/приёма почты, OCR/AI-извлечения КП, внешнего поиска поставщиков, проверки компаний, платежей и подписок. Все цены, поставщики, закупки и расчёты экономии в примерах демонстрационные.

## Публикация
В корне находится `render.yaml` с настройкой статического сайта `snabpro-demo`.
