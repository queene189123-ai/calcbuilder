# CalcBuilder — демоверсия v0.4

Русскоязычный no-code прототип конструктора калькуляторов стоимости услуг для сайтов малого бизнеса.

## Запуск
Откройте `public/index.html` в современном браузере. Для проверки автономного виджета откройте `public/widget-test.html`.

## Публикация на Render
В корне находится `render.yaml`. В Render выберите New → Blueprint, подключите этот репозиторий и проверьте, что создаётся только бесплатный Static Site `calcbuilder-demo`. Платные ресурсы и базы данных не нужны.

## Возможности
- Редактор калькулятора и пяти типов полей.
- Настройка цен, диапазонов, вариантов и доплат.
- Автоматический пересчёт.
- Темы оформления и desktop/mobile предпросмотр.
- Сохранение проектов и тестовых заявок в localStorage.
- Экспорт JSON и генерация embed-кода.

## Ограничения
Это фронтенд-демо, не production SaaS. Нет аккаунтов, облачной синхронизации, API, серверного приёма заявок, платежей и подписок. Данные хранятся только в текущем браузере. Не используйте реальные персональные данные.
