# СнабПро — кликабельная демоверсия системы снабжения

## Что можно тестировать
- Обзор закупок и показателей.
- Справочник материалов и база поставщиков: поиск, добавление, сохранение в браузере.
- Создание закупки, подбор поставщиков по категориям и просмотр подготовленного текста запросов.
- Раздел «КП и сравнение»: демонстрационные предложения, ручное добавление КП, импорт простых CSV/TXT/EML-таблиц, расчёт полной суммы с доставкой, сортировка по итоговой стоимости.
- Раздел «Отчёт руководителю»: сравнение по материалам и расчёт разницы между лучшим и самым дорогим предложением.
- Поиск поставщиков и рекомендации по экономии (демонстрационные данные).
- Выбор тарифа в окне «Тарифы и подписка».

## Данные и ограничения
В интерфейсе есть регистрация и вход через Supabase Auth, создание рабочего пространства предприятия, отдельные права доступа на уровне строк (RLS) и закрытое файловое хранилище для КП. PDF/XLSX/DOCX/DOC после входа и выбора предприятия загружаются в приватный bucket и получают запись со статусом «Загружен». Автоматическое AI/OCR-извлечение ещё не включено: для него нужен отдельный серверный обработчик и ключ AI-провайдера, который хранится только на сервере. CSV/TXT/EML пока разбираются простым локальным парсером, не AI. После входа и выбора предприятия справочник материалов, база поставщиков и закупки загружаются из Supabase и сохраняются в БД; у разных предприятий отдельные данные. Без входа интерфейс остаётся в демо-режиме с localStorage. Загруженные файлы КП видны в списке документов предприятия. Ручное добавление предложений в таблицу сравнения пока остаётся локальным и ещё не записывается в БД. Почтовая интеграция, подтверждённая отправка запросов, внешний поиск поставщиков и платежи не подключены. Вымышленные компании, предложения и суммы помечены как демонстрационные.

## Запуск
Откройте `public/index.html` в браузере или разверните каталог `public` как статический сайт.
